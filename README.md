## 部署与微信分享

游戏是纯静态页面，无后端，部署到任意静态托管即可用链接分享、在微信里直接打开（无需安装小程序）：

1. **GitHub Pages**：把本文件夹推到 GitHub 仓库 → Settings → Pages 开启，得到 `https://用户名.github.io/仓库名/` 链接。
2. **jsDelivr（国内访问友好）**：推送到 GitHub 后，直接用
   `https://cdn.jsdelivr.net/gh/用户名/仓库名@main/index.html`
   即可打开（微信内可直接访问）。
3. **Gitee Pages / 腾讯云静态网站托管 / 自有服务器**：把文件夹整体上传即可。

在微信中打开链接后，点右上角「···」即可转发给朋友或分享到群。

> 提示：部署后把 `index.html` 中 `og:image` 的注释所指路径改为你的绝对链接，微信分享卡片就会显示西电校徽缩略图。
